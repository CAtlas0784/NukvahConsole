# Data provenance and licensing

## What is bundled

`public/data/*.json` is generated by `scripts/build-catalog.mjs` from files the SnezhnayaCore
server already loads:

| Output | Source |
|---|---|
| characters, weapons, artifacts, materials, monsters, scenes | `resources/ExcelBinOutput/*.json` (AnimeGameData dump; artifacts partly AstaPS-Resource, MIT) |
| names (EN, TH) | `resources/TextMap/TextMap{EN,TH}*.json` incl. `TextMap_Medium*` |
| commands | `@Command` annotations in `src/main/java/emu/grasscutter/command/commands`, descriptions from `src/main/resources/languages/en-US.json` |

Bundled fields are identifiers, names, rarity, element/weapon type, stat pool IDs and values,
and icon *names* (strings). These are factual game data of the kind every Grasscutter GM handbook
publishes. Names and descriptions remain HoYoverse's intellectual property; this project makes no
claim to them.

## What is not bundled

**No images, icons, splash art, audio or fonts from the game.** Artwork is drawn as
deterministic generated sigils. If you have artwork you are allowed to use, host it yourself and
set `VITE_ASSET_BASE_URL` (or Settings → Artwork source); the console requests
`<base>/<IconName>.png` and falls back to the sigil on error.

Before deploying publicly, decide whether you are comfortable publishing the generated catalog.
To keep it private, deploy to a private host, or remove `public/data` from the repository and
generate it at build time in a private CI.
